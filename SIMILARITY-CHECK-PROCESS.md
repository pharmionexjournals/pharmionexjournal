# Similarity check process

The site says manuscripts above 10% similarity may be returned before peer review. Use this process so you can apply that fairly and keep a record.

## Tools
Pick one and confirm access **before** launch:
- **iThenticate / Crossref Similarity Check.** As far as I know this is offered to Crossref members, so check Crossref's current membership terms before relying on it.
- **Turnitin.** Many universities have it. A colleague with access may run checks for you if their institution allows it. Ask them first.
- **No paid tool yet (stop-gap).** Copy 8-10 distinctive sentences from the Introduction, Methods and Discussion into Google Scholar and a web search with quotation marks, and look for matching text. This is weaker, so say "manual check" in your record and consider a lower-risk first issue (invited authors you know).

## Steps
1. Download the manuscript file from the author's Drive folder.
2. Run the check. Where the tool allows it, exclude the reference list and quoted text.
3. Record in the Sheet (Plagiarism column): date, tool, overall %, and the largest single-source %.
4. Read the matches before deciding. Standard method phrases, reagent lists and ICH guideline wording are not misconduct.
5. Decide:
   - **Overall 10% or below, no large single-source overlap:** continue to peer review.
   - **Above 10%:** email the author the report summary and ask them to revise and resubmit. Do not send it to reviewers.
   - **Large copied blocks or the author's own earlier paper:** follow COPE guidance for text recycling, and keep the evidence.
6. Never forward a similarity report to anyone outside the journal. It contains the author's text.

## Decide now
- Does 10% include or exclude references?
- What single-source percentage triggers a manual read? (Many editors use about 3-5%.)
