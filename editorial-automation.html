Editorial operations

Intake and status
automation.

Pharmionex uses Google Forms, Sheets and Apps Script to automate acknowledgements, manuscript IDs, status notices, reviewer invitations and limited deadline reminders.

Form and tracker created: The manuscript intake form is ready, and the private tracker is available to the editorial account. The website now links to this form. Complete a non-editor test of responder access and Drive permissions before broad promotion or accepting live manuscripts.

What automation handles

  • Collect submission metadata and required declarations.
  • Assign sequential manuscript IDs, create a private status-check code for the corresponding author, and log each submission.
  • Send an author receipt with the manuscript ID and private status-check code, and alert the editorial inbox.
  • Email status updates when an editor changes the status.
  • Send reviewer invitations when an editor marks an invitation READY.
  • Send up to two reviewer/revision reminders.
  • On acceptance, create a private production checklist; after the team publishes the final article page/PDF and approves release, add the article to Current Issue and Archives automatically.

Editors still screen manuscripts, assess conflicts, select reviewers, make decisions, edit files, check proofs, publish pages and register identifiers. The live status-check web app returns only a general stage and update date after validating the private code. Acceptance opens a production checklist; editors still prepare and publish article HTML/PDF manually. Once the live files are verified and the checklist is marked Published, Current Issue and Archives list the article automatically. The script does not automate scholarly judgment, upload article files, or register DOIs.

Use and verify the live setup

  1. Open the manuscript intake form to submit a manuscript.
  2. Share manuscript files through a Drive folder shared directly with pharmionex.journal@gmail.com. Never use public link sharing for confidential manuscripts.
  3. The private editorial tracker is available in the journal Google account; share it only with authorized editors and reviewers as needed.
  4. Before accepting live manuscripts, test the form from a non-editor account. Confirm the author receipt, editor alert, manuscript ID, file access, and a status-update email.
  5. If a test submission is used, label it TEST and remove it from the operational tracker afterwards.

Full setup and operating guidance is included in the downloadable site ZIP under automation/SETUP.txt. Google Forms file links require authors to share access directly with the journal address; never request public access to confidential manuscripts.
